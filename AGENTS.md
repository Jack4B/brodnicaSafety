# AGENTS.md

## Rola agentów – Brodnica Alert

### Zasady

- Mobile first
- Lekkość i offline na pierwszym miejscu
- Anti-sloop
- Małe kroki + aktualizacja CLAUDE.md
- Hosting CT8

### Agenci

| Agent | Odpowiedzialność |
|-------|------------------|
| **Planner** | Struktura treści, konspekt, MVP |
| **Designer** | Makiety mobile first, design system |
| **Frontend** | Implementacja (lekka, PWA) |
| **Content** | Treści edukacyjne, checklisty |
| **Tester** | Responsywność, dostępność, offline, wydajność |
| **Deployer** | Wdrożenie na CT8 |

### Workflow

1. Planner → struktura
2. Designer → makiety → akceptacja
3. Frontend + Content
4. Tester
5. Deployer → CT8
6. Aktualizacja pamięci

### Definition of Done

- Mobile first
- Działa offline
- Lekka
- Intuicyjna
- Treści aktualne
- Wdrożona na CT8
