# Brodnica Alert Lifecycle

Lekka, mobilna strona informacyjno-edukacyjna o gotowości kryzysowej dla mieszkańców Brodnicy.

## Rekomendowane skille

```bash
npx skills add obra/superpowers
npx skills add nextlevelbuilder/ui-ux-pro-max-skill --skill ui-ux-pro-max
npx skills add mattpocock/skills
/plugin marketplace add anthropics/skills
/plugin install frontend-design@anthropics/skills
```

## Etapy

1. **Koncepcja** — struktura treści, sekcje, MVP.
2. **Makiety** — mobile first (Figma-like opis lub wireframe).
3. **Akceptacja** — przegląd i poprawki.
4. **Design system** — kolory, typografia, komponenty.
5. **Kod** — mobile first, lekki, PWA/offline.
6. **Testy** — responsywność, dostępność, offline, wydajność.
7. **Release** — wdrożenie na CT8.

## Zasady

- Mobile first
- Maksymalnie lekka
- Offline (PWA + możliwość pobrania)
- Intuicyjny UX
- Nowoczesny, czysty UI
- Anti-sloop (bez zbędnego AI w interfejsie)
- Treści łatwe do ręcznej aktualizacji
- Hosting CT8

Po każdym etapie aktualizuj CLAUDE.md.
